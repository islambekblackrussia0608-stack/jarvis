# 🤖 JARVIS - Голосовой ассистент

Голосовой ассистент на Python для Windows, вдохновленный JARVIS из фильмов о Железном человеке.

## 🚀 Возможности

- 🎤 Распознавание речи на русском языке
- 🗣️ Ответы голосом
- 🌐 Открытие браузеров (Chrome, Firefox, Edge)
- 📱 Открытие приложений (блокнот, калькулятор, проводник и др.)
- 🔍 Поиск в Google
- 🎬 Поиск видео на YouTube
- 💻 Управление ПК (выключение, перезагрузка)
- 📖 Справка по командам

## 📋 Требования

- Windows 10/11
- Python 3.8+
- Микрофон
- Интернет подключение

## 🔧 Установка

### 1. Клонируйте или загрузите проект
```bash
git clone https://github.com/islambekblackrussia0608-stack/jarvis.git
cd jarvis
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

**Важно для Windows:** Вам может понадобиться установить PyAudio отдельно:
```bash
# Если pip install не работает, скачайте .whl файл:
# https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
pip install PyAudio-0.2.13-cp311-cp311-win_amd64.whl
```

### 3. Проверьте пути браузеров в `config.py`
По умолчанию указаны стандартные пути. Если браузеры установлены в других местах, отредактируйте `config.py`.

## ▶️ Запуск

```bash
python main.py
```

## 🎙️ Команды

Произнесите одну из следующих команд:

| Команда | Описание |
|---------|----------|
| "Открой браузер" | Открыть Chrome |
| "Открой Firefox" | Открыть Firefox |
| "Открой Chrome/Edge" | Открыть нужный браузер |
| "Открой блокнот" | Открыть блокнот |
| "Открой калькулятор" | Открыть калькулятор |
| "Открой проводник" | Открыть проводник |
| "Ищи [запрос]" | Поиск в Google |
| "Найди видео [запрос]" | Поиск на YouTube |
| "Выключи компьютер" | Выключить ПК через 30 сек |
| "Перезагрузи компьютер" | Перезагрузить ПК |
| "Отмени выключение" | Отменить выключение |
| "Помощь" | Показать справку |
| "Выход" или "Пока" | Завершить программу |

## 🔧 Конфигурация

В файле `config.py` вы можете настроить:
- Имя ассистента
- Громкость и скорость речи
- Пути к браузерам и приложениям
- Приветствие
- Язык распознавания

## 🐛 Возможные проблемы

### Микрофон не работает
- Проверьте, включен ли микрофон в настройках Windows
- Попробуйте установить PyAudio вручную

### Распознавание не работает
- Проверьте интернет подключение
- Говорите громче и четче
- Проверьте уровень шума

### Браузер не открывается
- Отредактируйте пути в `config.py`
- Убедитесь, что браузер установлен

## 📝 Расширение функциональности

Добавить новые команды просто! Отредактируйте функцию `process_command()` в `commands.py`:

```python
elif "ваша команда" in command:
    return "Ответ ассистента"
```
